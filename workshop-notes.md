# Workshop Notes

## Hands-on GitHub collaboration - session checklist

1. Say hello and share GitHub usernames
2. Everyone forks or clones the sandbox repo
3. Create a feature branch with a descriptive name
4. Make a small, meaningful edit to a file
5. Commit with a clear, imperative commit message
6. Push the branch to the remote
7. Open a pull request with a helpful description
8. Request a review from a teammate
9. Leave an inline comment on at least one line of the diff
10. Approve or request changes, and respond to feedback
11. Merge the pull request once it is approved
12. Delete the branch after merging
13. Open an issue to track follow-up work
14. Run through the Actions tab to see workflow runs
15. Wrap up with questions and takeaways
